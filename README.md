# Weather Planner

A lightweight weather and packing suggestion app built with vanilla JavaScript.

## Setup

1. Copy `js/config.example.js` to `js/config.js`.
2. Replace `YOUR_OPENWEATHERMAP_API_KEY` with your OpenWeatherMap API key.
3. Open `index.html` in your browser or serve the folder using a local static server.

## Notes

- `js/config.js` is ignored by Git so your API key stays private.
- The app fetches weather data from OpenWeatherMap and shows a 3-day forecast plus packing suggestions.
